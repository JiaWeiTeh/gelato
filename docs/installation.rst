.. highlight:: rest.. _sec-running:Running GELATO==============To install----------GELATO is available at `https://github.com/JiaWeiTeh/gelato <https://github.com/JiaWeiTeh/gelato>`_. The easiest way to download a copy is via `git <http://git-scm.com/>`_. If you have git, you can download GELATO by doing::  git clone https://github.com/JiaWeiTeh/gelato.gitTo run------An example of running GELATO may look like this:.. code-block:: console    python gelato.py    Note: The above command is ran in the GELATO root directory.
